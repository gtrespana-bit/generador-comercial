1. Upload the data

For a cost breakdown in .xlsx, select one or more files. Line items, rows, cells and formulas are detected without flattening the data into a plain table. Tabular CSV/Excel and BC3 (FIEBDC-3) files are also supported.

You can select several files only if all of them are Excel breakdowns (.xlsx). BC3 files are uploaded one at a time.

Uncheck if the first row is already a line item.

Pasting accepts tabs, commas or semicolons. If you select a file, this field is ignored. You can also paste the contents of a .bc3 file.
