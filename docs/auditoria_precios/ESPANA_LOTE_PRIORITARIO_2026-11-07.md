## Descartes y próximos contrastes

- PVC sanitario 110 mm: dos ofertas de tubo encolable, pero el recurso menciona junta cementada; falta asegurar cómo se presupuesta el adhesivo y no se cambia el precio.
- Cinta enmascarar/embalaje y pasta/cinta de juntas: las ofertas aisladas no cubren inequívocamente ambos componentes descritos.
- Malla para encuentro con estructura: las dos ofertas encontradas son para juntas entre placas de yeso; no se ha acreditado equivalencia para encuentros entre materiales distintos.
- Bloque hueco 15×20×40: Obramat sí especifica hueco y precio, pero en la otra ficha consultada no se pudo verificar de forma inequívoca la geometría interior. No extrapolar a bloque estructural.
